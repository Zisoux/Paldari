# Pal다리
PalDari — 글로벌 매칭 및 실시간 번역 채팅 플랫폼

## 구조
- backend/ : Spring Boot API 서버
- frontend/ : Flutter 앱

### 상세
- 학과 해외단기연수 경험에서 아이디어를 얻어 Spring Boot와 Flutter를 활용한 모바일 서비스를 개발함.
- JWT 기반 인증, Google OAuth2, 이메일 인증 및 REST API를 구현함.
- WebSocket/STOMP 기반 실시간 채팅 기능을 구현하고 외부 번역 기능을 연동함.
- Spring Data JPA와 MySQL을 활용하여 백엔드 엔티티와 API를 설계함.
- 2인 개발팀으로 프로젝트를 진행함.
